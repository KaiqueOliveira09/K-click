Como dar acesso ao sistema para uma pessoa nova

1. Cadastre a pessoa aqui, com o usuário de login (ex: joana).

2. No Supabase, vá em Authentication → Users → Add user → Create new user, use o e-mail usuário (ex: joana), defina a senha e marque Auto Confirm User.

Quando alguém sair da empresa: desative a pessoa aqui e apague o usuário dela no Supabase (Authentication → Users).
